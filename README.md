# Controle Remoto

Use o tablet Android como mouse e teclado do notebook Windows, por Wi-Fi ou Bluetooth.

Downloads: aba **Releases** deste repositório.

- 1 dedo: mover · toque: clique · 2 dedos: rolar · toque com 2 dedos: clique direito
- Toque duplo e arraste: arrastar/selecionar
- Bluetooth: ative "Ancoragem Bluetooth" no tablet e conecte o notebook a ele como ponto de acesso.
